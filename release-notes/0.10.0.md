Offline edit merging, archive validation, and opt-in retention.

## Offline edit merging (Syncthing and other file-sync tools)
When two devices edit the same note while offline, file-sync tools keep one
version and drop the other next to it as a conflict copy — one side of your edits
silently loses. Sync Sentinel now remembers recent versions of your text files
(deduplicated, in the sync-excluded archive folder) and three-way merges those
conflict copies against the common ancestor:

- Edits to **different parts** of a note combine automatically.
- Edits to the **same lines** are flagged in the registry for one-click
  resolution (merge with markers / keep this device's / take the synced copy) —
  never guessed.
- Both versions are always preserved before any merge, and the conflict file
  goes to Obsidian's trash rather than being deleted.

Off by default. Auto-apply of clean merges can be turned off separately.

## Archive validation
A new command, *Validate keeper archives against synced shards*, hash-checks
every tracked file both ways — are the synced shards complete and uncorrupted,
and does this device's cold archive still match what the manifest promised?
Orphaned archive sets (no matching manifest) are surfaced too. Results appear in
the registry.

## Retention
Local safety copies (mirror versions, merge ancestors, resolved-conflict copies)
previously accumulated without bound. Retention is now configurable — but stays
**opt-in**: nothing is deleted by age until you enable it and choose the age
threshold and cadence. Each file's newest copy always survives, keeper shard
archives are never age-purged, and a dry-run preview shows exactly what a purge
would remove before you enable anything. The mirror's per-file version count is
now a setting too.
