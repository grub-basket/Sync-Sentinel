Broader conflict support, a version-history browser, and safer capture — so
multi-device editing reconciles without a race to notice a problem.

## Works with more sync tools
Conflict-copy detection is no longer Syncthing-only. Sync Sentinel now recognizes
conflict files from Syncthing (`.sync-conflict-…`), Dropbox ("conflicted copy"),
and Nextcloud, and merges them the same way.

## Local version history, browsable and restorable
Every text file now has a local version history you can open and restore from:
right-click a file → *Sync Sentinel: version history*, or use the command. Preview
any remembered version and restore it. Restores are non-destructive — the content
being replaced becomes a version too.

This is what removes the deadline: a silent last-writer-wins overwrite or a bad
automatic merge (including by Obsidian Sync, which writes no conflict file) is
fixable **whenever** you notice, not only while your sync service's own history
lasts.

## Safer capture
- Versions are now captured **immediately** on each save rather than after a
  short delay, so a sync overwrite arriving moments later can't erase work that
  only a pending capture knew about. Storage stays lean through content
  deduplication and history compaction.
- Fixed a case where a clean auto-merge could take the remote copy over a local
  edit made at nearly the same moment; the local edit is now always preserved.
