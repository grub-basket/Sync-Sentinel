Read the free-sync guide without leaving Obsidian.

- New command **Open the free DIY sync guide** (and a button under Settings →
  Misc) opens the sync guide in a window, rendered, right inside the app — no
  need to hunt for it on GitHub. Nothing leaves your vault.
- The guide covers syncing desktop↔mobile (including iOS) for free: Remotely
  Save + object storage, **Supabase for locked-down machines with no admin
  rights**, Self-hosted LiveSync, Syncthing, and Git — plus where Sync Sentinel
  fits in.
- The in-app guide and the copy in this repo are the **same source** (bundled at
  build time), so they can't drift, and the guide now carries a "last updated"
  date and version at the bottom.
