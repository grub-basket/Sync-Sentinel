A UI-polish release focused on the settings tab, plus packaging for public
distribution.

## Settings — path fields

- **Ghost text on every destination field.** The mirror destination and the
  sync-log archive destination were missing the placeholder text that the backup
  destination already had. All three now show an example path, so an empty field
  reads as "here's what goes here" rather than a blank box.
- **Vault-folder autocomplete everywhere a folder is named.** Every path field —
  the three destinations, plus the vault-relative shard folder and the keeper
  archive folder — now offers Obsidian's own folder autocomplete
  (`AbstractInputSuggest`, new `util/folderSuggest.ts`) instead of a bare text
  box, so you pick an existing folder instead of retyping it.
- **Live "exclude this from sync" reminder.** Choosing or typing a path that sits
  inside your vault now shows an inline reminder to exclude it from sync — a
  backup or mirror that syncs back on itself defeats its own purpose. The reminder
  adapts to Syncthing mode, pointing at the managed `.stignore`. The
  inside-the-vault check is pure string work, so it triggers no Node-module load
  (and no load notice).

## Packaging

- Added `LICENSE` and `versions.json`, and adopted a `docs/public/` convention so
  only user-facing docs are published. Groundwork for the public repo.
