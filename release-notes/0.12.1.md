A redesigned command center.

The registry (now called the **command center**) used a narrow modal with
fixed-width rows, so long note and file paths ran off the edge and forced
horizontal scrolling — half the content sat off-screen. It's rebuilt:

- The modal is now wide (up to 1000px, or 94% of the window) and scrolls
  vertically only. Long paths **wrap** instead of overflowing.
- Sections render as cards, and the things that need your attention — blanked
  notes and edit conflicts — float to the top with a colored border.
- The largest-files overview fits within the modal, with an ellipsized name
  column so it can't push the layout wide.

No behavior changed — every action (reconstruct, conflict resolution, keeper and
purge controls, recovery) is exactly where it was, just laid out clearly.
