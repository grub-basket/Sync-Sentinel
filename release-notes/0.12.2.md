Small follow-ups to the 0.12.1 redesign.

- The **version-history** window got the same treatment as the command center:
  it's now wide with vertical-only scrolling, so long file paths and content
  previews wrap instead of forcing horizontal scrolling. (Both windows now share
  one layout helper.)
- Documentation: the free-sync guide gained a **Supabase Storage + Remotely
  Save** walkthrough for people on locked-down computers who can't install
  Syncthing or run a server — it's all a plugin plus a cloud account, nothing to
  install on the machine.
